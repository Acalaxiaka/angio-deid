# angio-deid 冠脉造影文件批量脱敏工具（离线、免安装）

单个 `angio-deid.exe`，双击即用，**无需联网、无需安装**，支持 Windows 10 / 11（64 位）。
本仓库只含工具代码，不含任何患者数据。

## 使用说明
1. 双击 `angio-deid.exe`（首次启动约 5–15 秒解压）。若 Windows 提示“已保护你的电脑”，点“更多信息 → 仍要运行”。
2. 点 **选择文件**（可多选）/ **选择文件夹**，或把文件、文件夹（含光盘 DICOM 目录）直接拖入列表。程序递归扫描，按内容识别 DICOM（无扩展名也可），并识别 AVI/MP4 等视频。DICOMDIR 索引文件会跳过。
3. 选择 **脱敏输出文件夹** 和 **对照表文件夹**（对照表含真实姓名/ID，必须留在院内电脑，建议与输出分开）。
4. 选择遮挡方式：**自动检测文字区域**（边缘区域静止高对比文字）/ **四角黑框**（可调宽高百分比）/ **不遮挡**。
5. 点 **开始脱敏**。可随时取消；单个文件出错会跳过并记录。完成后自动复查输出。

## 输出
- `P0001/STUDY01/SERIES001/IMG0001.dcm`（视频为 `VIDEOS/V0001.mp4`，H.264）
- `manifest_时间.csv`：编号、性别、年龄段、模态、帧数、主/副角度、投照标签（如 `LAO 45 CAU 20`）等，无隐私，可作训练标签。
- `对照表_MAPPING_含隐私_勿外传_时间.csv`：编号 ↔ 原 ID/姓名/原路径。**严禁外传。**

## 处理规则（参考 DICOM PS3.15 附录 E 基本规范）
- 删除：姓名、ID、出生日期、地址、电话、机构、科室、各类医师/操作者、检查号、设备序列号、站名、注释等；删除全部私有标签、覆盖层(60xx)、曲线(50xx)；未在白名单中的文本标签一律删除。
- 日期：同一患者统一随机前移 30–3650 天（保持时间间隔）。UID：一致重映射（同一批次内保持研究/序列关系）。
- 保留：性别、年龄、主/副角度(0018,1510/1511)、帧时间/帧率、KVP、源像距、像素间距、行列数、帧数、序列描述、协议名、厂商型号。
- 设置 PatientIdentityRemoved=YES、DeidentificationMethod。压缩图像（JPEG/JPEG2000/RLE）解码后以无压缩格式保存。
- 视频：清除全部元数据，按所选方式遮挡后重新编码为 H.264 MP4。
